> O **Fibonacci** é uma plataforma web desenvolvida com **Django** que conecta artistas locais e amantes da arte, oferecendo uma galeria digital para exposição e gerenciamento de obras únicas.

## ✨ Sobre o Projeto

O projeto foca na valorização da arte regional, permitindo o cadastro de artistas e suas respectivas obras categorizadas. A interface foi construída com foco em elegância e responsividade, utilizando uma paleta de cores creme e marrom.

### Funcionalidades Atuais (O que já fiz):
- **Modelagem de Dados**: Estrutura completa de modelos para `Artista` e `Obra` (com categorias como Pintura, Cerâmica, Desenho e Fotografia).
- **Configuração de Ambiente**: Setup de diretórios estáticos, templates globais e integração com banco de dados SQLite3.
- **Interface Responsiva**: Layout modular utilizando Bootstrap e CSS customizado para Navbar, Home e Footer.
- **Organização de Apps**: Divisão lógica do projeto com o app `artistas` e pasta de configuração `setup`.
---

### 🛠️ Em Desenvolvimento (Próximas Etapas)

O projeto está em fase de implementação de funcionalidades dinâmicas. Os próximos passos são:

- [ ] **Painel Administrativo**: Customizar o `admin.py` para facilitar o cadastro de novas obras e artistas.
- [ ] **Filtros por Categoria**: Implementar lógica nas views para filtrar obras por tipo (ex: apenas Cerâmica).
- [ ] **Página de Detalhes**: Criar a rota e o template para exibir a biografia completa do artista e detalhes da obra.
- [ ] **Sistema de Busca**: Implementar a barra de pesquisa funcional na navbar.
---

## 💻 Pré-requisitos

Antes de começar, verifique se você atendeu aos seguintes requisitos:

- Você instalou a versão mais recente de `Python 3.x`.
- Você possui o `pip` (gerenciador de pacotes do Python) instalado.
- Recomendado: Uso de ambiente virtual (`venv`).
---

## 🚀 Instalando Fibonacci

Para instalar o Fibonacci, siga estas etapas:

Linux, macOS e Windows:

# Clone o repositório
```bash
git clone https://github.com/emillymarrocos/projeto_galeriaartes
```
# Entre no diretório
```
cd projeto_galeriaartes
```
# Crie e ative um ambiente virtual
```
python -m venv venv
# No Windows: venv\Scripts\activate
# No Linux/macOS: source venv/bin/activate
```
# Instale o Django
```
pip install django
```

## ☕ Usando Fibonacci
Para iniciar o servidor de desenvolvimento, execute:
```
python manage.py runserver
```
Acesse http://127.0.0.1:8000 no seu navegador.
